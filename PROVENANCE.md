## Personal data and secrets

* The CSV columns are identifiers (`C#####`, `P####`, `ORD######`), categorical attributes, timestamps and amounts. There are no names, e-mail
  addresses, phone numbers or street addresses, and the customer ids look synthetic. This was checked by reading the headers and scanning
  the repository, not by contacting the course provider, so it is a reasonable assumption rather than a guarantee.
* A scan of the notebooks (source **and** saved outputs), reports and documents found no AWS access keys, tokens, secret ARNs, account numbers,
  e-mail addresses, IP addresses or home-directory paths. The only environment identifier is the lab workgroup name `udacity-dwh-wg`.
  `tests/test_schema_artifacts.py` repeats the credential scan on every run.

## Options (all need the owner's decision; none was done)

1. **Verify** (keeps the repository public and unchanged if the answer is yes; costs a wait if it is not). Read the course's terms of use or ask Udacity support whether the data, DDL and starter structure may be republished. Add a license
   to the repository only after that, and only for the owner's own contributions.
2. **Make the repository private** until the answer is known (removes the risk going forward, but recruiters can no longer see the project, the CI badge stops resolving for visitors, and copies already cloned or cached stay out there).
3. **Keep it public but replace the supplied material**: generate synthetic data with the same schema (the tests already build such data in
   `tests/synth.py`), re-derive the DDL and diagram from the owner's own design, and rewrite the notebook's introductory scaffolding. This changes
   the link between the recorded run and the data in the repository, so the historical reports would then need a note saying they came from the
   original course data. Not done without approval.
4. **Do nothing** and accept the risk that the supplied files stay public without a license.

Git history already contains the supplied files, so options 2–3 do not remove them from earlier commits without a history rewrite, which was
deliberately not done.
